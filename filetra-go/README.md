# FileTra · 局域网文件传输

一个**单文件、零依赖、开箱即用**的局域网文件传输工具。双击运行，同一 Wi-Fi 下的手机、平板、其他电脑打开浏览器即可互传文件和文本。

```
Go + 内嵌网页 → 一个 exe（约 7MB）
```

## ✨ 功能

| 功能 | 说明 |
|------|------|
| 📂 文件浏览 | 网页直接浏览共享目录，支持子目录、筛选、排序、新建文件夹 |
| ⬇️ 下载 | 单文件下载（支持 HTTP Range **断点续传**）；点击文件可在线预览图片/文本/音视频 |
| 🗜️ 打包下载 | 整个文件夹流式打包 zip 下载，不占内存不落盘 |
| ⬆️ 上传 | 拖拽或选择文件/整个文件夹上传；**4MB 分片 + 服务端校验，中途断网自动续传** |
| 💬 文本速递 | 设备间传剪贴板文本/临时便签，全端自动同步，持久保存最近 100 条 |
| 📡 附近设备 | UDP 广播自动发现同网段运行的 FileTra，一键跳转对方共享目录 |
| 📱 扫码连接 | 自动生成二维码，手机扫码打开、扫码上传 |
| 🕘 传输记录 | 收发历史自动记录并持久化（最多 500 条） |
| 🔒 访问密码 | 可选 `-password` 开启 Basic Auth 保护 |

## 🚀 快速开始

```powershell
# 默认：共享 exe 所在目录，端口 5050，自动打开浏览器
.\filetra.exe

# 共享指定目录
.\filetra.exe -dir D:\电影

# 带访问密码（用户名固定为 filetra）
.\filetra.exe -dir D:\共享 -password 我的密码
```

启动后会打印访问地址（如 `http://192.168.1.10:5050`），其他设备：

1. 连接**同一个 Wi-Fi / 网段**
2. 浏览器访问该地址，或直接用手机相机扫"设备"页的二维码
3. 即可上传、下载、互传文本

> 首次运行 Windows 可能弹出防火墙询问，请选择 **允许**（涉及 TCP 服务端口与 UDP 52020~52027 广播）。

### 参数

| 参数 | 默认 | 说明 |
|------|------|------|
| `-dir` | 当前目录 | 要共享的目录 |
| `-port` | 5050 | HTTP 端口，被占用时自动顺延 |
| `-name` | 计算机名 | 设备显示名称 |
| `-password` | 无 | 访问密码（Basic Auth，用户名 `filetra`） |
| `-no-browser` | false | 启动后不自动打开浏览器 |

## 🛠 构建

需要 Go 1.24+，一键构建所有平台单文件：

```powershell
.\build.ps1     # Windows
./build.sh      # Linux/macOS（如有需要可自行改写）
```

产物矩阵（8 个平台）：

| GOOS | GOARCH | 说明 |
|------|--------|------|
| windows | amd64 / arm64 / **386** | Win 10+（amd64）、ARM 版、**32 位 Win 7~10 老机器** |
| linux | amd64 / arm64 / **386** | 服务器、树莓派、**32 位老设备** |
| darwin | amd64 / arm64 | Intel 老 Mac / M 系列 |

> 注意：客户端浏览器（手机/其他电脑）无任何系统要求，能开现代浏览器即可。

手动构建本机版本：

```bash
go build -trimpath -ldflags "-s -w" -o filetra.exe .
```

## 📐 架构说明

```
filetra.exe
├── main.go        入口 / 路由 / 认证 / 横幅
├── api.go         列表、下载(Range)、zip 流式打包、二维码、文本、历史
├── upload.go      分片上传会话管理（init/chunk/status/complete/abort）
├── discovery.go   UDP 广播设备发现（同机多开互不冲突）
├── store.go       历史与文本的 JSON 持久化（写入数据目录）
├── util.go        路径安全、文件名清洗、局域网 IP 探测
└── web/           内嵌前端（原生 JS/CSS，无第三方依赖）
```

**上传断点续传原理**：前端把文件按 4MB 顺序分片 `POST /api/upload/chunk?id=&offset=`；服务端校验 `offset` 与已接收字节数严格相等才追加写入，否则返回真实进度（防止重试导致重复内容）；请求失败时前端查询 `/status` 获得服务端进度，从断点继续。下载则由 `http.ServeContent` 原生提供 Range 支持。

**数据位置**：历史记录与文本保存在 `%APPDATA%\filetra\`（Windows）或 `~/.config/filetra/`（Linux/macOS）。上传临时文件为共享目录内 `.ftpart-` 前缀的隐藏文件，完成后自动改名（同名自动加 `(1)`）。

## 🔐 安全说明

- 默认**无鉴权**，局域网内任何人可访问。公网/不放心时请使用 `-password`
- 严格限制路径在共享目录内（防 `..` 穿越），文件名做非法字符清洗
- 删除操作需网页中手工确认
